# Room Card Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in "Room Card" composite to Bento Box (status-summary text line +
per-subsystem status icon row on top of the existing icon+label card), usable for both
residential and commercial projects, without changing the existing plain-card path at
all.

**Architecture:** One new module, `generator/room_card.py::build_room_card`, builds one
composite card: the existing `ch5-button` (unchanged navigation mechanism, re-tuned
icon position) stays the card's only interactive element; a new `ch5-text` status line
and new icon-only `ch5-button`s for the subsystem row are non-interactive overlays
(`pointer-events: none`, confirmed real via Construct's own wifi-gauge component).
`layout_patterns.py::build_bento_box_page` gains an opt-in `room_cards` parameter (same
per-label-dict shape as its existing `icons` parameter) that calls `build_room_card`
instead of the plain button for a given item; every existing call site and test that
doesn't use it is unaffected.

**Tech Stack:** Python 3, no new dependencies. Test convention: standalone scripts
under `generator/_test_output/`, run directly with `python <file>.py` (no pytest; a
test passes when it prints its OK lines and exits 0 — see any existing `*_test.py` in
that folder, e.g. `bento_box_test.py`, for house style: module docstring citing what's
confirmed vs. a policy call, plain `assert`, a print per assertion group, a final "all
assertions passed" line).

**Spec:** `docs/superpowers/specs/2026-09-16-room-card-design.md`.

## Global Constraints

- **Backward compatibility:** every new parameter on `build_bento_box_page` defaults to
  today's exact behavior. No existing assertion in `bento_box_test.py` may change
  because of this plan.
- **Content is always caller-supplied.** `status_text` and `subsystems` (which icons,
  which are active) are never invented by the generator — same precedent as
  `theme_chat.py`'s chat-resolved colors and the plain card's own `icons` param.
  `subsystems` is a fully open list, no fixed vocabulary (confirmed with the user: this
  must serve commercial projects, e.g. a boardroom's AV/occupancy/HVAC row, not just
  residential rooms).
- **Large/wide tiers only.** `build_bento_box_page` raises `ValueError` if a `small`-
  tier item is given `room_cards` content — a 242×242-scale card has no real room for
  three stacked bands (see spec's **Tier restriction**).
- **Raise rather than silently overflow/degrade**, same discipline as every other
  layout-pattern builder in this project (`_layout_row`, `build_bento_box_page`'s own
  touch-target/height checks).
- **`README.md`'s Log gets an entry in the same turn as any completed task** — this
  project's own hard rule, not unique to this plan.
- **`generator/_test_output/` test scripts are the only tracked files in that
  directory** (`.gitignore` excludes everything else) — running a test creates output
  files that do NOT need `git add`.

### Step 3: Implement `generator/room_card.py`

```python
"""
Bento Box "Room Card" composite (ConstructUISkill_DesignSystem.md §1, Bento Box
pattern) -- see docs/superpowers/specs/2026-09-16-room-card-design.md for the full
design. Adds a status-summary text line and a per-subsystem status icon row on top of
the existing Bento Box card, restricted to large/wide tiers (see
layout_patterns.py::build_bento_box_page's `room_cards` param).

Mechanism: the base ch5-button stays the card's ONLY interactive element (unchanged
navigation mechanism); the new ch5-text status line and the new icon-only ch5-buttons
for the subsystem row are pure decorative overlays, marked `pointer-events: none` so a
tap anywhere on the card still reaches the base button underneath -- confirmed real via
Construct's own generator, which writes the identical `pointer-events:none` declaration
on `ch5-wifi-signal-level-gauge`'s inner container for exactly this reason
(`C:\\Solutions\\ClaudeSamples\\Components\\Component - Gauge - Wifi.cuig`). Written via
`layout.update_element_declarations` -- a literal CSS property, not a `--ch5-*`
schema-catalog var, so `style.set_component_style` (which always resolves a
schema-confirmed target_property) is the wrong tool for this one declaration; it IS the
right tool for the subsystem icons' color (a real, catalog-confirmed property).

Base button icon: re-tuned from the plain Bento card's centered "hero" icon to a small
icon next to the room/space name at the top-left (`iconposition="first"` -- the
schema's own default -- + `halignlabel="left"` + `valignlabel="top"`), freeing vertical
space for the two new overlay bands below it. All 3 values are confirmed real schema
enums (`component._schema_element(sdk, "ch5-button")`, 2026-09-16).

Vertical layout: card height splits into 3 bands top to bottom -- icon+name (the base
button's own rendering, ICON_NAME_BAND_FRACTION of height), status text
(STATUS_BAND_FRACTION), subsystem icon row (SUBSYSTEM_BAND_FRACTION) -- separated by
spacing.SPACING_UNIT gaps, inset spacing.EDGE_PADDING from the card's left/right edges.
Base button label/icon size reuses layout_patterns.bento_card_type_sizes (the SAME
proportional formula the plain Bento card uses, not a duplicate). Status text size is
STATUS_TEXT_RATIO of that label size, floored at typography.TYPE_SCALE["caption"].
Subsystem icon size is SUBSYSTEM_ICON_RATIO of the subsystem band's own height, floored
at typography.ICON_SCALE["label"]. All fractions/ratios verified (this module's own
test) to fit real Bento Box card sizes at both the large (2x2) and wide (2x1) tiers
this is restricted to, without overflow.

Subsystem row layout deliberately does NOT reuse layout_patterns._layout_row (the
footer's row-layout helper) -- that helper enforces spacing.MIN_TOUCH_TARGET, which is
wrong here: these icons are non-interactive decorative status indicators, not real
touch targets. `_layout_subsystem_row` below is the same evenly-spaced-with-gaps shape,
without the touch-target floor.
"""
from __future__ import annotations

import component
import layout
import palette
import spacing
import style
import typography
from elements import Element
from layout_patterns import bento_card_type_sizes
from page import generate_element_id
from sdk import UiSdk

#: Fraction of card height given to each band, top to bottom. Judgment call (not a
#: Construct spec) -- verified against real Bento Box card sizes (this module's test)
#: to fit without overflow at both tiers Room Card is restricted to.
ICON_NAME_BAND_FRACTION = 0.50
STATUS_BAND_FRACTION = 0.15
SUBSYSTEM_BAND_FRACTION = 0.15

#: Status text size relative to the base button's own (proportional) label size, and
#: subsystem icon size relative to its own band's height -- both floored at the design
#: system's own §3 readability minimums so neither ever drops below a normal UI
#: text/icon floor.
STATUS_TEXT_RATIO = 0.6
SUBSYSTEM_ICON_RATIO = 0.7


def _layout_subsystem_row(
    item_count: int, row_x: int, row_y: int, row_width: int, row_height: int, icon_px: int,
) -> list[tuple[int, int]]:
    """`(x, y)` for `item_count` square `icon_px`-sized decorative icons, evenly spaced
    across `row_width` with spacing.SPACING_UNIT gaps, vertically centered in
    `row_height`. See module docstring for why this is NOT layout_patterns._layout_row.
    Raises ValueError if `item_count` doesn't fit at `icon_px` within `row_width`."""
    if item_count == 0:
        return []
    gap_total = spacing.SPACING_UNIT * (item_count - 1)
    total_width = icon_px * item_count + gap_total
    if total_width > row_width:
        raise ValueError(
            f"{item_count} subsystem icons at {icon_px}px each need {total_width}px, "
            f"but the row is only {row_width}px wide -- fewer subsystems or a wider card"
        )
    y = row_y + (row_height - icon_px) // 2
    positions = []
    x = row_x
    for _ in range(item_count):
        positions.append((x, y))
        x += icon_px + spacing.SPACING_UNIT
    return positions


def build_room_card(
    sdk: UiSdk, *, component_name: str, element_id: str, x: int, y: int,
    width: int, height: int, resolution: tuple[int, int] | None,
    icon_class: str | None, icon_library: str | None, active_font: str,
    status_text: str, subsystems: list[tuple[str, str, bool]],
    active_color: str, inactive_color: str = palette.NEUTRAL_SCALE["neutral_mid"],
    primary_query: str | None = None,
) -> tuple[str, str, list[Element]]:
    """`(html, css, elements)` for ONE composite Room Card. See module docstring for
    the full mechanism. Raises `ValueError` if the 3 bands don't fit within `height`,
    or if `subsystems` doesn't fit within the row's width at the computed icon size."""
    gap = spacing.SPACING_UNIT
    icon_name_h = round(height * ICON_NAME_BAND_FRACTION)
    status_h = round(height * STATUS_BAND_FRACTION)
    subsystem_h = round(height * SUBSYSTEM_BAND_FRACTION)
    consumed = 4 * gap + icon_name_h + status_h + subsystem_h
    if consumed > height:
        raise ValueError(
            f"a {width}x{height} card can't fit the icon+name/status/subsystem bands "
            f"({consumed}px needed) -- build_room_card needs a taller card"
        )

    icon_kwargs = {} if icon_class is None else {"icon_class": icon_class, "icon_library": icon_library}
    button_html, button_css, button_element = component.build_component(
        sdk, "ch5-button", component_name=component_name, element_id=element_id,
        x=x, y=y, width=width, height=height, z_index=1, resolution=resolution,
        label=component_name, active_font=active_font, **icon_kwargs,
    )
    for attr, value in (("iconposition", "first"), ("halignlabel", "left"), ("valignlabel", "top")):
        button_html = style.set_html_attribute(button_html, element_id, attr, value)
    label_px, icon_px = bento_card_type_sizes(width, height)
    button_css = typography.apply_font_size(
        button_css, element_id, sdk, "ch5-button", label_px, primary_query=primary_query)
    if icon_class is not None:
        button_css = typography.apply_icon_size(
            button_css, element_id, sdk, "ch5-button", icon_px, primary_query=primary_query)

    status_id = generate_element_id()
    status_px = max(round(label_px * STATUS_TEXT_RATIO), typography.TYPE_SCALE["caption"])
    status_y = y + gap + icon_name_h + gap
    status_html, status_css, status_element = component.build_component(
        sdk, "ch5-text", component_name=f"{component_name} Status", element_id=status_id,
        x=x + spacing.EDGE_PADDING, y=status_y, width=width - 2 * spacing.EDGE_PADDING,
        height=status_h, z_index=2, resolution=resolution, label=status_text,
        active_font=active_font, overrides={"labelinnerhtml": status_text},
    )
    status_css = typography.apply_font_size(
        status_css, status_id, sdk, "ch5-text", status_px, primary_query=primary_query)
    status_css, _ = layout.update_element_declarations(
        status_css, status_id, {"pointer-events": "none"},
        extra_queries=() if primary_query is None else (primary_query,))

    subsystem_icon_px = max(round(subsystem_h * SUBSYSTEM_ICON_RATIO), typography.ICON_SCALE["label"])
    subsystem_row_y = status_y + status_h + gap
    row_positions = _layout_subsystem_row(
        len(subsystems), x + spacing.EDGE_PADDING, subsystem_row_y,
        width - 2 * spacing.EDGE_PADDING, subsystem_h, subsystem_icon_px)

    elements = [button_element, status_element]
    html_parts = [button_html, status_html]
    css_parts = [button_css, status_css]
    icon_color_class, icon_color_prop = palette.PALETTE_MAPPING["ch5-button"]["icon_color"]
    for (sub_icon_class, sub_icon_library, active), (sx, sy) in zip(subsystems, row_positions):
        sub_id = generate_element_id()
        sub_html, sub_css, sub_element = component.build_component(
            sdk, "ch5-button", component_name=f"{component_name} Subsystem", element_id=sub_id,
            x=sx, y=sy, width=subsystem_icon_px, height=subsystem_icon_px, z_index=2,
            resolution=resolution, label="", active_font=active_font,
            icon_class=sub_icon_class, icon_library=sub_icon_library,
            overrides={"labelinnerhtml": ""},
        )
        color = active_color if active else inactive_color
        sub_css = style.set_component_style(
            sub_css, sub_id, sdk, "ch5-button", [(icon_color_class, icon_color_prop, color)],
            primary_query=primary_query)
        sub_css, _ = layout.update_element_declarations(
            sub_css, sub_id, {"pointer-events": "none"},
            extra_queries=() if primary_query is None else (primary_query,))
        elements.append(sub_element)
        html_parts.append(sub_html)
        css_parts.append(sub_css)

    return "".join(html_parts), "".join(css_parts), elements
```
